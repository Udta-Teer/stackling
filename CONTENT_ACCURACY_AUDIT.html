Highest-risk defects corrected

Rate-limiter request path

Before: the token-bucket shard forwarded the API request and 500k checks/sec had no shard capacity. Now: six explicitly sized shards return decisions to the gateway; only the gateway calls the backend after ALLOW.

Passive stores acting like proxies

Idempotency stores, connection registries, and caches were drawn forwarding payments, messages, or reads. The caller now queries state and performs the subsequent action itself.

Missing components

The “cache-first redirect” card had no cache, the connection-registry card had no registry, and the source-of-truth card had no propagation path. Their diagrams now depict the mechanism named by the lesson.

Wrong arithmetic

The observability exercise claimed the mean of 95×80ms, 4×500ms, and 1×6,000ms was 95.7ms. The correct mean is 156ms; p99 remains 500ms.

HTTP safety vs idempotency

DELETE and PUT were called “safe.” They are idempotent but not safe in HTTP terminology. The matching answer and explanation now teach both properties separately.

Stateful definition

“Stateful” was defined as “copies must agree.” A component is stateful when retained information affects later operations; replication and consistency are separate design choices.

p99 definition

A checkpoint called p99 “the worst 1%.” It is a threshold at or below which 99% of observations fall—not a set of requests.

False total ordering

Asynchronous replication and provider callbacks were presented as strict sequences. The lessons now identify optional timelines and explicitly state which events may race.

Dual-write gaps

Signup/email and refresh-token rotation used separate state changes. They now use atomic outbox or atomic credential-rotation transitions and explain retry behavior.

Unsafe migration ordering

The migration flow backfilled before explicitly enabling dual writes. It now starts compatible writes first and prevents a backfill from overwriting newer production data.

Split-brain transfer

A regional authority transfer treated network unreachability as sufficient. It now requires protocol-backed fencing; a timeout cannot prove the old writer stopped.

Spatial hot-spot claim

A neighbourhood surge was said to hit “exactly one shard.” Boundary-aware spatial queries can touch adjacent cells and partitions; the corrected answer describes a localized hot area.

Cache absolutes

CDN hits were described without the hit condition, and versioned filenames were said to eliminate all staleness. The revised text distinguishes asset identity from stale HTML references and cache misses.

NoSQL folklore

“Not only SQL” was presented as the definition. It is now described as a later expansion of a broad industry label; product data models and guarantees are what matter.

Regression gates added

The validator now rejects: DELETE/PUT mislabeled HTTP-safe, p99 described as the “worst 1%,” cache-first diagrams with no cache, shard-sizing questions with traffic but no per-shard capacity, and passive authorities drawn forwarding requests to compute.

Verification

Green: JSON and schema validation, source-to-prototype synchronization, answer ranges, diagram topology structure, spoiler detection, all 12 renderers, phone-width diagram behavior, and the first-session prototype. Browser result: 173 + 21 passed, 0 failed.

Honest limitation

This is substantially safer, not mathematically “proven accurate.” Architecture correctness depends on assumptions and failure models that static validation cannot infer.
